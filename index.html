Dark Web එක ගැන ගොඩක් අය අහලා තිබුණට, ඒක ඇතුළේ මොකද වෙන්නේ කියලා හරියටම දන්නේ ඉතාම ටික දෙනෙක් විතරයි. අන්තර්ජාලයේ අඳුරු පැත්ත විදිහට හඳුන්වන මේ ලෝකය ඇතුළේ අපිට හිතාගන්න බැරි තරම් දේවල් සිද්ධ වෙනවා. ඔන්න අද අපි කතා කරමු මොකක්ද මේ Dark Web කියන්නේ සහ ඒකට යන්න කලින් දැනගන්නම ඕන ආරක්ෂිත පියවර වගේම අවශ්‍ය කරන Tools ගැන.

🕸️ මොකක්ද මේ Dark Web කියන්නේ?

අපි සාමාන්‍යයෙන් Google, YouTube, Facebook යන ඒවා අයිති වෙන්නේ "Surface Web" එකට. ඒ කියන්නේ ඕනෑම කෙනෙක්ට පේන අන්තර්ජාලයේ මතුපිට ස්ථරයයි. හැබැයි අන්තර්ජාලයේ 90% කටත් වඩා ලොකු කොටසක් තියෙනවා සාමාන්‍ය Google Search Engine වලට අහු නොවන. ඒක තමයි Dark Web එක. මෙතැනදී පාවිච්චි වෙන්නේ විශේෂ ලිපින (.onion) සහ විශේෂ Browsers විතරයි. මෙතැනදී හැමෝම ඉන්නේ නිර්නාමිකව (Anonymous).

🛡️ කොහොමද Dark Web එකට ආරක්ෂිතව යන්නේ?

Dark Web එකට යන එක ලේසි වුණාට, එතැනදී ඔයාගේ පෞද්ගලික දත්ත සහ උපකරණයේ (Phone/PC) ආරක්ෂාව තහවුරු කරගන්න එක අමාරුයි. ඔයාට ඔයාගේ වටිනා තොරතුරු ආරක්ෂා කරගන්න ඕනෙනම් මේ පියවර ටික පිළිවෙලට කරන්න.

1. Tor Browser එක පාවිච්චි කරන්න.
සාමාන්‍ය Chrome හෝ Safari වලින් මේකට යන්න බැහැ. අනිවාර්යයෙන්ම Tor (The Onion Router) Browser එක ඕන. මේකෙන් ඔයාගේ IP Address එක ලෝකය වටා Nodes කිහිපයක් හරහා යවන නිසා ඔයාව හොයාගන්න අමාරුයි.

  • Tor Browser for Android (Play Store)
  • Tor Browser for Windows/Mac (Official)

2. විශ්වාසවන්ත VPN එකක් භාවිතා කරන්න.
Tor එකට යන්න කලින් VPN එකක් On කරගන්න. මේකෙන් වෙන්නේ ඔයාගේ Internet Provider (SLT/Dialog/Mobitel) ට පවා ඔයා Dark Web එකට යනවා කියන එක හංගන එක. ඔය පහල දාල තියෙන ඒව පාවිච්චි කරන්න.ඔයා ලග වෙන හොද එකක් තියේනම් ඒකෙන් යන්න

  • Proton VPN (Best Free/Secure)
  • Windscribe VPN

3. පෞද්ගලික තොරතුරු ආරක්ෂා කරගන්න ඕනේ.
කිසිම වෙලාවක ඔයාගේ ඇත්ත නම, ඇත්ත Email එක, Phone Number එක හරි ඔයා සාමාන්‍යයෙන් පාවිච්චි කරන Password එකක් Dark Web අඩවි වලට ඇතුළත් කරන්න එපා.ඒකේ ඉන්න Hackers ලට ඉතාම ඉක්මනින් ඔයාගේ විස්තර ගන්න පුළුවන්.

4. උපකරණයේ ආරක්ෂාව ගැනත් හිතන්න ඕනේ යකොව්. (Hardware Safety).
Dark Web එකේ ඉන්න Hackers ලාට පුළුවන් ඔයා නොදැනුවත්වම ඔයාගේ කැමරාවට Access ගන්න. ඒ නිසා කැමරාව Cover කරලා තියාගන්න. ඒ වගේම JavaScript Disable කරලා (Tor Settings -> Security Level -> Safest) පාවිච්චි කරන එක තමා හොඳ. ලින්ක් Click කරනකොට ඔය ඔලුගෙඩිය අස්සේ තියෙන එක පාවිච්චි කරන්න🧠.

Dark Web එකේ ඉතාම දරුණු නීති විරෝධී දේවල් තියෙනවා. ආයුධ, මත්ද්‍රව්‍ය සහ වෙනත් අසභ්‍ය දේවල් තියෙන අඩවි වලට යෑම ලොකු නීතිමය කරදරයක් ඉල්ලගෙන කෑවා වෙන්න පුළුවන්. ඒ නිසා නිකමටවත් නීති විරෝධී දේවල් සොයන්න එපා.
