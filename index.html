Dark Web එක ගැන ගොඩක් අය අහලා තිබුණට, ඒක ඇතුළේ මොකද වෙන්නේ කියලා හරියටම දන්නේ පොඩි දෙනයි. ඔන්න අද අපි කතා කරමු මොකක්ද මේ Dark Web කියන්නේ සහ ඒකට යන්න කලින් දැනගන්නම ඕන ආරක්ෂිත පියවර ගැන.

🕸️ මොකක්ද මේ Dark Web කියන්නේ?

අපි සාමාන්‍යයෙන් Google, YouTube යන ඒවා අයිති වෙන්නේ "Surface Web" එකට.(ඕක ගැන අපි කලින් කියලා තියෙනවනේ.) හැමෝටම පේන හරිය ඒක. හැබැයි අන්තර්ජාලයේ තව ලොකු කොටසක් තියෙනවා සාමාන්‍ය Search Engine වලට අහු නොවන. ඒක තමයි Dark Web එක. මෙතැනදී හැමෝම ඉන්නේ නිර්නාමිකව (Anonymous).

🛡️ කොහොමද Dark Web එකට යන්නේ?

Dark Web එකට යන එක ලේසි වුණාට, එතැනදී ඔයාගේ ආරක්ෂාව තහවුරු කරගන්න එක අමාරුයි. ඔයාට ඔයාගේ වටිනා තොරතුරු ආරක්ෂා කරගන්න ඕනෙනම් මේ දේවල් අනිවාර්යයෙන් කරන්න.
